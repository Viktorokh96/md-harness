# AGENTS.md — CONTROL ROOM

> Инструкция для LLM-агентов, работающих с этим проектом.

## Что это

`inline-vibe/` — система древовидного диалога через markdown. Пользователь и агент общаются внутри ` ```agentsmindmap ` блока в markdown-файле (по умолчанию `CONTROL_ROOM.md`).

Формат:

````markdown
```agentsmindmap
root: CONTROL ROOM
* сообщение пользователя
  [*] ответ агента
    * уточнение пользователя
      [*] ответ агента
* другая тема
```
````

- `root:` — корень (название комнаты), обязательная первая строка.
- `*` — узел пользователя.
- `[*]` — узел агента.
- 2 пробела = один уровень вложенности.
- ID узлов — dot-notation: `root.1`, `root.1.1`, `root.1.1.1`.

## [hide] — скрытие веток

Маркер `[hide]` после тега схлопывает ветку в одну строку-резюме:

```
*[hide] Резюме скрытой ветки
[*][hide] Архивный ответ
```

- **Скрытая ветка**: дети не отображаются в `.md` и outline/mermaid.
- **Полное дерево**: сохраняется в `.graph.json` sidecar-файле.
- **Тоггл мгновенный**: добавление/удаление `[hide]` обрабатывается препроцессором без вызова LLM.
- **Unhide восстанавливает**: удаление `[hide]` возвращает полное поддерево из `.graph.json`.

## Многострочный контент

Строки без маркера `*`/`[*]` на том же или дочернем уровне — продолжение контента:

```
* Первая строка мысли
  продолжение здесь
  и здесь
  [*] Ответ агента
```

## Ключевые файлы

| Файл | Роль |
|------|------|
| `CONTROL_ROOM.md` | Mind map диалога (видимая часть). **НЕ ТРОГАТЬ без явной просьбы.** |
| `.CONTROL_ROOM.md_graph.json` | Полное дерево (включая скрытые ветки). Автосоздаётся. |
| `agent.py` | Агент на OpenAI Agents SDK. 7 инструментов. |
| `watcher.py` | inotify-наблюдатель (watchfiles) + синхронизация `.graph.json` + CLI. |
| `tests/` | Тесты: 94 штуки, 4 файла. |

## Запуск

```bash
python3 watcher.py [путь] [--once] [--dry-run] [--model MODEL]

- `[путь]` — по умолчанию `CONTROL_ROOM.md`. Если нет — создаётся шаблон.
- `--once` — один проход вместо непрерывного вотча.
- `--dry-run` — показать diff без вызова LLM.
- `--model` — модель (по умолчанию из `LLM_MODEL`).
## Инструменты агента

| Tool | Назначение |
|------|-----------|
| `read_mindmap()` | Прочитать дерево из `.graph.json` (outline с ID и 📦 для hidden) |
| `add_reply(parent_id, text)` | Добавить узел-ответ под `parent_id` |
| `find_nodes(query)` | Поиск по содержимому (case-insensitive) |
| `stay_silent()` | Промолчать |
| `run_shell(cmd)` | Shell-команда в корне проекта |
| `read_file(path)` | Прочитать любой файл проекта |
| `delegate_task(task)` | Делегировать Worker-агенту (Agent.as_tool()) |

## Поток данных

```
CONTROL_ROOM.md
  │ изменение обнаружено watcher'ом
  ├─ _sync_graph(): парсинг .md, загрузка .graph.json, merge, сохранение
  ├─ diff только [hide]? → выход (без LLM)
  ├─ иначе → агент читает дерево из .graph.json
  │   ├─ read_mindmap() → outline с ID
  │   ├─ add_reply() → новый узел + сохранение в оба файла
  │   └─ stay_silent() → без ответа
  └─ .graph.json + .md обновлены
```

## Соглашения

- Узлы пользователя: `*`, узлы агента: `[*]`.
- Вложенность: 2 пробела на уровень.
- Иконки агента: `❓` вопрос, `▶` действие, `✅` факт/решение.
- `[*] ...thinking...` — временный плейсхолдер, удаляется после ответа.
- Тестовый файл: `CONTROL_ROOM_TEST.md` (используй `--file CONTROL_ROOM_TEST.md`).

## Разработка

```bash
# Тесты
python3 -m pytest tests/ -v

# Быстрый тест
python3 watcher.py CONTROL_ROOM_TEST.md --once

# Dry run
python3 watcher.py CONTROL_ROOM_TEST.md --once --dry-run
```
