# AGENTS.md — CONTROL ROOM

> Инструкция для LLM-агентов, работающих с этим проектом.

## Что это

`inline-vibe/` — система диалога через mind map. Пользователь и агент общаются
в markdown-файле (по умолчанию `CONTROL_ROOM.md`). Формат:

```
* сообщение пользователя                   <- глубина 0
	[*] ответ агента                         <- глубина 1 (на один tab глубже)
		[*] уточняющий вопрос                  <- глубина 2
			* ответ пользователя                 <- глубина 3
```

## Ключевые файлы

| Файл | Роль |
|---|---|
| `CONTROL_ROOM.md` | Mind map диалога. **НЕ ТРОГАТЬ без явной просьбы пользователя.** |
| `agent.py` | Агент на OpenAI Agents SDK: ControlRoom + Worker (as_tool) |
| `watcher.py` | Poll-наблюдатель: мониторит файл, вызывает агента при изменениях |
| `.env` | API-ключи (DeepSeek по умолчанию). **НЕ коммитить.** |
| `pyproject.toml` | Зависимости: `openai-agents>=0.18` |

## Запуск

```bash
python3 watcher.py [путь_к_файлу.md] [--once] [--dry-run] [--model MODEL]
```

- `[путь]` — по умолчанию `CONTROL_ROOM.md`. Если файла нет — создаётся из шаблона.
- `--once` — один проход вместо непрерывного вотча.
- `--dry-run` — показать diff без вызова LLM.

## Инструменты агента

| Tool | Назначение |
|---|---|
| `append_to_control_room` | Дописать `[*]` строки в mind map |
| `stay_silent` | Явно промолчать |
| `run_shell` | Выполнить shell-команду в корне проекта |
| `read_file` | Прочитать файл (включая сам mind map) |
| `delegate_task` | Делегировать задачу Worker-агенту (`Agent.as_tool()`) |

## Архитектура

```
watcher.py (poll mtime, 1s)
  │
  ├─ изменение обнаружено
  ├─ пишет [*] ...thinking... (плейсхолдер)
  ├─ запускает process_change()
  │   └─ Runner.run_sync(ControlRoom, prompt)
  │       ├─ read_file("CONTROL_ROOM.md") — прочитать полный контекст
  │       ├─ delegate_task → Worker.run_sync()
  │       │   └─ run_shell / read_file → результат
  │       └─ append_to_control_room() / stay_silent()
  └─ удаляет [*] ...thinking...
```

## Соглашения

- Пользователь начинает строку с `*`, агент — с `[*]`.
- Вложенность — табами. Ответ на один уровень глубже сообщения.
- Иконки агента: `❓` вопрос, `▶` действие, `✅` факт/решение.
- `[*] ...thinking...` — временный плейсхолдер, удаляется после ответа.
- Тестовый файл: `CONTROL_ROOM_TEST.md`. Для тестов используй `--file CONTROL_ROOM_TEST.md`.
