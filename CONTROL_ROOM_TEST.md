```agentsmindmap
* Привет
* Как работает inotify?
  [*] ✅ inotify — это подсистема ядра Linux для отслеживания событий файловой системы (создание, удаление, изменение, запись и т.д.). Через `inotify_init()` создаётся дескриптор, `inotify_add_watch()` регистрирует интерес к каталогу/файлу, а события читаются из fd через `read()`. Классический пример — `inotifywait -m /path`.
```
