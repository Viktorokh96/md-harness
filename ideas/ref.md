# `[[root.2.1]]` / `*[ref]` — кросс-ссылки и бэклинки

Препроцессор строит индекс ссылок, внизу узла рендерится «связанные обсуждения». Дерево вырастает в граф знаний, merge-логика уже почти готова в tree_engine.

## Формат
- `[[root.2.1]]` — ссылка на узел по ID
- `*[ref] Связанная тема` — узел-ссылка
- Бэклинки: при рендеринге узла показывать «связанные: root.1, root.3»

## Реализация
- Парсер: ищет `[[<id>]]` в контенте
- `MindNode.refs: list[str]` — список ID, на которые ссылается узел
- `MindNode.backrefs: list[str]` — список ID, которые ссылаются на узел (вычисляется)
- `to_outline()`: 🔗 маркер для ref-узлов
- Индекс: `_ref_index: dict[str, set[str]]` для быстрого поиска бэклинков
