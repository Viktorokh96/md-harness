# `*[ ]` / `*[x]` — задачи в дереве

Чекбоксы прямо в маркере, препроцессор рендерит прогресс в outline (▸ 3/7), агент по запросу выдаёт сводку «что осталось» и следит за незакрытыми.

Тот же паттерн, что [hide] — чисто синтаксис, без нового кода хранения.

## Реализация
- Парсер: `*[ ]` → `task_status="open"`, `*[x]` → `task_status="done"`
- Поле `MindNode.task_status: str = ""`
- `to_outline()`: `☐` / `☑` маркеры
- `serialize_mindmap()`: round-trip маркера
- `diff_trees()`: не считать переключение чекбокса за content change (как hide)
- Агент: `find_nodes("task_status=open")` → список незакрытых
