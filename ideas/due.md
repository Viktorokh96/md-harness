# `*[due: 2026-08-08]` — дедлайны и напоминания

Препроцессор подсвечивает просроченные узлы, агент при следующем ходе сам напоминает о приближающихся сроках.

Проактивность без планировщика — просто маркер + проверка при чтении diff.

## Реализация
- Парсер: `*[due: YYYY-MM-DD]` → `MindNode.due_date: str`
- `to_outline()`: ⏰ для просроченных, ⏳ для сегодня, 📅 для будущих
- Агент: перед ответом проверяет `find_nodes("due")` → если есть просроченные, напоминает
- Опционально: `*[due: 2026-08-08] Напомнить про деплой`
