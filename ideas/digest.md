# `*[digest]` — авто-сводка ветки без выноса

LLM одним абзацем резюмирует поддерево прямо в узел (как [archive], но ветка остаётся на месте и редактируемой). Отлично для «что решили в root.3» перед новой встречей.

## Отличие от [archive]
- `[archive]`: дети удаляются из графа, поддерево → archive/, в .md только резюме
- `[digest]`: дети остаются в графе, сводка добавляется как отдельное поле, рендерится под узлом

## Реализация
- Парсер: `*[digest]` → `MindNode.digest: str = ""`
- `summarize()` (из archiver.py) генерирует digest (тот же one-shot LLM)
- `to_outline()`: показывает digest строкой `📝 сводка: ...`
- `serialize_mindmap()`: round-trip с `*[digest]` маркером
- Агент: `add_digest(node_id)` — вызывает summarize и сохраняет
- Опционально: авто-digest по расписанию (cron)
