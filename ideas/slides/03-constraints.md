# Ограничения — честная рамка (цифры из кода)

```
NDA → данные не покидают периметр
  → локальная модель qwen3.5-coder (vLLM, 10.54.20.116:8000)
  → окно модели ~80k токенов (вход+выход суммарно)
  → нельзя закинуть всё в контекст
  → контекст управляется на каждом уровне:
      • история диалога: 12k токенов (CTX_MAX_CONTEXT_TOKENS) + Summarizer при 85%
      • RAG предзагрузка: top-5 документов до запуска агента
      • узкие субагенты: каждый промпт влезает в окно
```

**Тезис:** 80k — не слабость, а причина, по которой мы построили систему
из специализированных агентов. Управление контекстом — не «костыль под лимит»,
а нормальная инженерная практика: ограниченное окно заставляет строить
RAG-индексацию и узких агентов — это и есть корпоративный ИИ.

- Большой контекст = лениво «всё в один промпт» → дорого, мусор, потеря точности
- 80k = RAG top-5 + 12k истории + узкие субагенты → в контекст попадает только нужное
- NDA/локальность — растущий тренд: многие заказчики сами не отдают данные в облако
