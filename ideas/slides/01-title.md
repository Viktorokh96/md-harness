# ИИ-помощник для системы расчёта ТП
## «Корпоративная память системы» — одна точка входа в её знание

> Заказчик и внутренний разработчик упираются в один и тот же барьер:
> сложная доменная система (нефтепереработка), знания разбросаны.
> Помощник снимает этот барьер для обоих → ускоряет одно и то же:
> **путь от вопроса к работающему коду**.

- Для заказчиков: быстро сориентироваться, освоить систему без «расспроса гуру»
- Для внутренней разработки: быстрый поиск доменного знания, меньше онбординг-болтовни
- Одна система, два применения — единая нить презентации
