# Метрики: цифры УЖЕ собираются системой — осталось их выгрузить

**Формула:** время до верного ответа = латенси +X · точность +Y · итерации −Z

| Метрика | Откуда берётся в системе | Монолит | Субагенты |
|---|---|---|---|
| Латенси | ⏱ в attachment каждого ответа (`time.monotonic` вокруг Runner.run) | быстрый | медленнее (+X, worst case известен) |
| Точность | QualityCard: `answer_quality` 0–1 после каждого ответа | ниже (мусор в контексте) | выше (+Y) |
| Итерации | `user_satisfaction`: thanked / asked_again / reacted / silent | много переспросов | меньше (−Z) |
| Обратная связь | 👍/👎 кнопки на карточке ответа → DebugServer :9100 | — | — |
| Пробелы | счётчик `note_add(gap)` — неотвеченные вопросы | — | падает (цикл закрытия) |

**Данные уже пишутся**: `data/analyst_runs.jsonl`, QualityCard в RAG,
сессии в `data/conversations.sqlite`. X/Y/Z = выборка из них, не «надо мерить с нуля».
