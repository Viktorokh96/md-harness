# Архитектура (факт из кода): главный агент + 3 субагента через agent.as_tool()

```
Mattermost (WebSocket) → MattermostClient → AgentBot
                                              │
                                              ▼
┌──────────── ГЛАВНЫЙ АГЕНТ (Agency, «ассистент техподдержки») ────────────┐
│  короткий промпт: маршрутизация + формат ответа                          │
│  (Ответ / Источники / Уверенность, иерархия: код > RAG > история)       │
│                                                                          │
│  [SYSTEM] предзагруженный RAG-контекст — поиск ДО запуска (top-5)       │
│                                                                          │
│  Субагенты как типизированные инструменты (agent.as_tool = handoff):    │
│  ├─ rag_agent      → RAG MCP (hybrid_search, доки/ADR/спеки)            │
│  ├─ code_agent     → code-review-graph MCP (AST-граф: вызовы, blast)    │
│  ├─ gitlab_agent   → GitLab MCP (MR, пайплайны, коммиты, диффы)         │
│  └─ notebook       → прямой MCP-инструмент (фиксация «пробелов»)        │
└──────────────────────────────────────────────────────────────────────────┘
   │
   ├─ История диалога: SQLiteSession (per channel/thread) + Summarizer
   │     (сжатие при 85% лимита — управляемые 12k токенов истории)
   ├─ Прогресс в чате: BotRunHooks ⚙️→🔨→👷→🧠 → ✅
   └─ Ответ: карточка ⏱ время + кнопки 👍/👎 (feedback → DebugServer :9100)

Фон (cron): SystemAnalyst — читает «пробелы» из notebook, закрывает их
через тех же субагентов → база знаний растёт без участия человека
```

- **Главный агент = тонкий роутер**: решает «предзагруженного контекста хватит? → субагент → фиксация пробела». Не лезет в код сам.
- **Субагент = узкий эксперт**: свой промпт + свой MCP-сервер; в контекст главного агента попадает только *результат* вызова, а не весь его контекст.
- **Явная маршрутизация**: `agent.as_tool()` — субагент вызывается как инструмент с описанием; кто что делал видно в трассировке → аудит под NDA.
- **Pre-retrieval injection**: RAG ищет по вопросу ДО запуска → на простые вопросы агент не тратит ни одного вызова субагента (быстрый путь < 2с).
- **Замкнутый цикл**: не нашёл → `note_add(gap)` → ночной аналитик закрывает пробел → завтра ответ уже есть.
